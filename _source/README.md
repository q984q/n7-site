# Внутренние материалы (без цен)

Этот репозиторий **публичный**, поэтому точные цены из котировки партнёра здесь не хранятся —
ни в файлах, ни в истории коммитов. Их нельзя было бы убрать простым удалением: любой
желающий увидел бы прежнюю редакцию файла в истории GitHub.

Авторитетный источник — исходный PDF `price list-N7.pdf` (Hebei Enlio Sports Goods Co., Ltd,
QUOTATION LIST, FOB Tianjin, USD за м²), который остаётся у заказчика. Рабочие копии лежат
**вне репозитория**, в папке `/home/user/n7-site-private/`, и в git не добавляются:

- `price list-N7.pdf` — оригинал котировки;
- `price-list-N7.md` — разобранная таблица со всеми позициями и ценами.

## Что видно на сайте

Публикуются только три ориентира «от» по категориям (рулонные покрытия, модульная плитка,
беговые дорожки) и пометка «Цена по запросу» у каждой карточки. Точных цен нет ни в HTML,
ни в CSS/JS. Публичный прайс-лист и контакты производителя на сайте не размещаются.

## При выкладке

`_source/`, `tools/`, `README.md`, `_config.yml` и исходный архив `n7-site.zip` исключены
из сборки GitHub Pages через `_config.yml`. Локальный превью-сервер `tools/serve.py`
дополнительно отдаёт `404` на служебные пути.

## Вопросы к партнёру

Единица цены для модульной плитки (за м² или за плитку), MOQ и сроки поставки, актуальность
котировки, действующие сертификаты, разрешение на использование фото из прайс-листа,
условия гарантии и возможность отправки образцов в Казахстан.
