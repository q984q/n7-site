Спортивный паркет для залов

Спортивный паркет из массива дерева на системе килей с амортизаторами создаёт упругое основание для баскетбола, волейбола, бадминтона, настольного тенниса и фитнеса. Панель покрывается противоскользящей износостойкой UV-краской, разметка наносится по проекту.

Упругое основание для зала

Спортивный паркет из массива дерева на системе килей с амортизаторами создаёт упругое основание для баскетбола, волейбола, бадминтона, настольного тенниса и фитнеса. Панель покрывается противоскользящей износостойкой UV-краской, разметка наносится по проекту.

Общие характеристики

  • Поглощение ударов ≥53%.
  • Отскок мяча ≥90%.
  • Коэффициент трения скольжения 0,4–0,6.
  • Эмиссия формальдегида по классу E1.
  • Ресурс покрытия подтверждается проектом.

Породы дерева

Канадский клён, китайский клён, берёза, дуб, сосна, каучуковое дерево. Подбираются под тип зала и требуемую эстетику.

  • Канадский клён
  • Китайский клён
  • Берёза
  • Дуб
  • Сосна
  • Каучуковое дерево

Конструкции

КонструкцияОсобенности
Двойной кильПрофессиональные залы, высокий уровень амортизации.
Одинарный кильЭкономичное решение, высота киля 40/50 мм.
Пластинчатый кильБыстрый монтаж, для залов с ограниченной высотой.
Многослойный паркет из массива (серии S, D, F)Готовые панели с покрытием, в том числе с цветным рисунком.
Модульный паркетСборно-разборные щиты 1800×917 мм, для залов и сцен.
Вентилируемая конструкция с наклоном 45°Подходит для залов с подогревом пола.

Применение

Школы и вузы, спорткомплексы, клубы, многофункциональные залы.
