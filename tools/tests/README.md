# UI-тесты сайта

```bash
cd tools/tests
npm i
npm test
```

`test-rails.cjs` поднимает все 18 HTML в jsdom, выполняет их defer-скрипты и
проверяет, что:

- на каждой странице ровно ожидаемое число листаемых лент (`n7-rail.js`);
- у каждой ленты есть стрелки, счётчик `1 / N`, `tabindex` и `aria-label`;
- ленты не попали в слайды презентации, каталог покрытий и каталог освещения;
- в панели управления нет «точки» (`<i>`, `.tprog`), в dock нет `.dock-i.on::before`;
- кнопка «→» меняет счётчик; бегущая строка заменена статичными чипами;
- дубль `id="sec-3"` на `o-kompanii.html` устранён.

Геометрию и реальные обрезки jsdom не считает — для этого снимаются скриншоты
Chromium (1440×900 и 390×844) и замеряется `documentElement.scrollWidth`.
Тесты форм и Telegram-воркера лежат в `tools/telegram-proxy/tests/`.
