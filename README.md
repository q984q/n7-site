# N7 Construction — сайт

Статический сайт компании N7 Construction (строительство, развитие, инфраструктура, Казахстан и СНГ).
Исходники получены от партнёров архивом `n7-site.zip`, распакованы в корень; сам архив из этой ветки удалён как дубликат (оригинал остался в `main`).
Дополнительно прислан прайс-лист `price list-N7.pdf` (Hebei Enlio Sports Goods) — на его основе сделан раздел «Продукция».

## Версия 4.1 «РЕДАКЦИЯ» (2026-11-10) — текущий дизайн

Полная смена визуального языка после бенчмарка казахстанских и мировых
компаний: Skanska, VINCI, AECOM, Arup, Turner, Bechtel, Webuild, Ferrovial,
STRABAG, HOCHTIEF, Bouygues и Obayashi. От v3 не сохранены тёмная канва,
WebGL-башня, HUD, изометрия, tilt и параллакс. Главным доказательством стала
крупная архитектурная фотография и спокойная редакционная сетка.

| Токен | Значение | Роль |
| --- | --- | --- |
| `--void` / `--ink` | `#F4F3EF` / `#FFFFFF` | бумага, белые секции, шапка |
| `--fg` / `--mut` | `#101820` / `#5A6672` | чернила и второстепенный текст |
| `--cyan` / `--amber` | `#B83A18` / `#B83A18` | один терракотовый акцент: кнопки, ссылки, активное меню |

| `--r-sm` … `--r-xl` | `2–4 px` | почти прямые углы карточек и кнопок |

- **Первый экран:** заголовок слева, диптих проверенных проектов
  `img/hero-projects.webp` (Almaty Arena и Tamos Space School) справа, подпись

- **Внутренние страницы:** компактная редакционная шапка — хлебные крошки,
  сдержанный заголовок, пояснение и правый мета-столбец `N7 / KZ · CIS`

- **Сетки и карточки:** плоские белые блоки с разделителями в 1 px, тонкая

## Версия 3 «ГЛУБИНА» (2026-11-09) — архив, заменена v4

Третий вариант сайта: **объёмный интерфейс без внешних библиотек**. Полностью новая
визуальная система, не наследующая палитру v2. Решения: гибрид (WebGL-сцена +
CSS-3D), раскатка на все 19 страниц, приоритет — выразительный визуал при сохранении метрик
и доступности.

| Токен | Значение | Роль |
| --- | --- | --- |
| `--void` | `#05080F` | пространство сцены, hero, подвал |
| `--ink` | `#070B14` | канва страниц |
| `--cyan` | `#4DE8DC` | свет, кнопки, акценты, рёбра 3D-объекта |
| `--amber` | `#FFB45C` | второй источник света, маркеры, заглушки |
| `--fg` / `--mut` | `#EAF3FA` / `#A8BCD0` | текст на тёмном (контраст ≥ 9:1) |

- **WebGL-сцена первого экрана** (`n7-scene.js`, ~16 КБ, чистый WebGL2): сборная
  башня из 7 плит, стеклянные этажи, несущие колонны, светящиеся рёбра, ядро с
  тёплым светом, перспективная сетка пола, туман и 190 светящихся частиц. Два
  источника света, блики, френель. Камера реагирует на указатель и прокрутку,
  объект медленно вращается. Поверх — сдержанная чертёжная рамка, подписи
  городов, направления работ и опыта; рядом — карточка реального объекта.
- **Никакого Three.js и CDN.** Собственный микро-рендерер: одна программа для
  тел/стекла/рёбер/пола, вторая для пыли. Это в 40 раз легче бандла и не влияет
  на LCP (LCP-элемент — текст h1).
- **CSS-3D на всех 19 страницах** (`n7-depth.js` + `n7-bold.css`): `preserve-3d`
  и tilt карточек по указателю, параллакс слоёв `[data-depth]`, изометрическая
  плита в каждом pagehero, стеклянные панели с `backdrop-filter`, световой блик,
  подсвеченные кромки, перспективная сетка.
- **Безопасные фолбэки:** мобильные ≤900 px, `prefers-reduced-motion`, отсутствие
  WebGL2, потеря контекста и программный рендерер (SwiftShader/llvmpipe) получают
  статичный CSS-объект вместо сцены; при software-рендерере рисуется ровно один
  кадр, поэтому TBT = 0. Пауза при уходе из вьюпорта и скрытой вкладке.
- **Ассеты перегенерированы:** 19 OG-превью с изометрической башней
  (`tools/make_og.py`), favicon SVG/PNG/ICO и `manifest.json` (`#05080F`).
- **Сохранено без изменений:** 19 URL, `sitemap.xml`, canonical/OG/Twitter,
  26 JSON-LD, телефоны `+7 (777) 884-88-18` / `+7 (747) 534-40-14`,
  `https://wa.me/77778848818`, только проверенные факты, 29 заглушек, обе формы
  с отправкой через WhatsApp, поиск ⌘K, квиз, каталог, карта, презентация.

Проверки: `tools/tests` (4 набора × 19 страниц), `screens/redesign-check.txt`
(19 × ПК/МОБ, WebGL/фолбэки, 3D-слои), `screens/lighthouse.txt`, 14 PNG в

## Запуск локально

Сайт полностью статический, сборка не нужна:

```bash
python3 tools/serve.py
```

Открыть `http://localhost:3000/`. Важно открывать именно через HTTP: при `file://` часть скриптов и шрифтов работает некорректно.

`tools/serve.py` — тот же статический сервер, но он не отдаёт `_source/`, `tools/`, `.git/`, исходный архив и служебные `.md`/`.py`: служебные материалы не должны попадать в публичный доступ. Обычный `python3 -m http.server` для превью использовать не стоит — он отдаёт все файлы подряд.

## Заявки → Telegram (безопасно)

Статический GitHub Pages **не может хранить токен бота**: любой JS виден посетителю.
Поэтому секрет живёт только в Cloudflare Worker, а сайт знает лишь публичный URL.
Полная инструкция — `tools/telegram-proxy/README.md`; кратко:

1. Токен, который был прислан в чате, надо отозвать у `@BotFather` и выпустить новый:
   он светился в открытом виде.
2. `cd tools/telegram-proxy && npx wrangler deploy`, секреты — `npx wrangler secret put
   TELEGRAM_TOKEN` и (необязательно) `TELEGRAM_CHAT_ID`. Если chat id не задан, воркер
   возьмёт последний чат из `getUpdates` — достаточно написать боту один раз.
3. Полученный `https://…workers.dev` задать как `window.N7_LEAD_ENDPOINT` либо
   `data-endpoint` у `<form id="lead">`. Это **публичный** URL, его можно коммитить.

Что куда уходит:

| Источник | Путь |
|---|---|
| Форма `kontakty.html` (имя, телефон, направление, комментарий, лист подбора) | `POST` JSON → воркер → `sendMessage` |
| Результат квиза, калькулятор, лист подбора / КП | `n7Send()` → тот же воркер, `kind: quick`, без контактов |
| Если воркер недоступен | автоматический fallback на WhatsApp `wa.me/77778848818` + текст для копирования |

Воркер: CORS только для `https://q984q.github.io`, honeypot-поля, лимиты длины,
валидация телефона, HTML-экранирование, пометка «без контактных данных» для быстрых заявок.

`npm test` в `tools/telegram-proxy` (форма, быстрые заявки, мок Bot API) (мок Bot API,

## Как теперь работает форма заявки

`main.js` поддерживает два режима:

1. **`N7_LEAD_ENDPOINT` задан** — форма отправляет `POST` с JSON на защищённый прокси,
   валидирует имя, телефон и согласие, очищает поля и показывает «Заявка отправлена».
2. **Сервис не подключён** — браузер собирает текст заявки, открывает WhatsApp
   с готовым сообщением и показывает кнопки «Отправить в WhatsApp», «Скопировать текст»,
   «Позвонить» плюс сам текст. Ссылки `kontakty.html?p=<артикул>` подставляют артикул
   в комментарий.

Точные цены, реквизиты и e-mail в репозиторий не добавляются.

## Каталог: анимации и освещение (`catalog-fx.js`)

Подключён на `produktsiya.html`, `sportivnye-pokrytiya.html`, `proekty.html`, `index.html`.

- **Живой счётчик** «Показано N позиций из 13» с `aria-live`; ambient-подсветка фона секций.
- Полная деградация при `prefers-reduced-motion` и на устройствах без `Element.animate`.

Результат уходит в WhatsApp, цен не публикуем.

Расчёт — оценка методом светового потока (КИ 0,45–0,55, КЭ 0,8, 130 лм/Вт), **не** заменяет DIALux/Relux и проект. Для объектов в Казахстане уровни, GR, Ra и вертикальную освещённость при ТВ-съёмке подтверждают проектом по действующим нормам и требованиям федерации.

## Новый пакет: конверсия, поиск, квиз и ревизия интерфейса

Реализовано без внешних библиотек, сервисов и публикации цен. Все модули — ванильный JS
с `defer`, все состояния доступны с клавиатуры, `prefers-reduced-motion` и
`prefers-contrast` уважаются.

**Конверсия без бэкенда**
- **Лист подбора** (`n7-list.js`): соберите покрытие, корт, свет и результат квиза в один
  запрос КП. `localStorage`, счётчик в шапке, ссылка `?cfg=` (UTF-8 base64url),

- **Поиск** (`n7-search.js`): ⌘K / Ctrl+K / `/`, 100 записей локального индекса
  (страницы, разделы, инструменты), `?q=`, на 404 открывается сам и подставляет путь в запрос.
- **Мастер заявки** (`n7-wizard.js`): 3 шага (объект → контакты → отправка), черновик
  в `localStorage`, валидация на каждом шаге и кнопка «Заполнить обычной формой».
  Логика отправки и WhatsApp-fallback остаются в `main.js`.
- **Квиз** (`n7-quiz.js`, `sportivnye-pokrytiya.html#quiz`): 6 шагов, мультивыбор приоритетов,
  две рекомендации, класс освещения, площадь, кнопки «в WhatsApp», «в лист подбора»,
  «пройти заново». Рекомендация помечена как предварительная.
- **Сравнение** 2–3 покрытий рядом, **димер** яркости III / II / I, синхронизированный
  с классом в расчёте освещения, и **Before/After**-ползунок (затемнение той же
  иллюстрации корта, честно подписанное как иллюстрация, а не фото объекта).

**Скорость и SEO**
- Self-hosted шрифты вместо Google Fonts, preload основного WOFF2 и LCP-изображения.
- 18 уникальных OG-превью (`tools/make_og.py`), `BreadcrumbList` на всех страницах с


1. **Ctrl+F5** (Windows) / **⌘+Shift+R** (Mac) — принудительно перезагрузить CSS и JS.

- **Кинематографичный вход.** На всех 19 страницах при первом открытии сайта
